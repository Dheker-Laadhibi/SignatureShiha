# SignatureShiha

Ce projet full-stack contient :
- 🎯 Un frontend Angular (`angular-auth-app`) : interface de connexion, inscription, signature, profil client.
- 🧠 Une intégration d'IA pour la reconnaissance ou traitement de signature.
- 🔧 Un backend Django (`django`) : API REST, gestion des utilisateurs, stockage sécurisé.

## Fonctionnalités principales
- Authentification sécurisée
- Gestion des utilisateurs et profils
- Système de signature numérique
- Intégration AI pour validation ou reconnaissance
